# ⚡ Samir Alam — Developer Portfolio & AI Assistant

> A futuristic, immersive developer portfolio built with a **Cyber-Minimalist Dark Theme**, animated project showcases, real-time coding stats, and **"Meet My AI"** — an integrated conversational AI assistant powered by **Groq** and **Vercel Serverless Functions**.

🔗 **Live Demo:** [https://samir-portfolio-ai.vercel.app/](https://samir-portfolio-ai.vercel.app/)

---

## ✨ Highlights

- 🤖 **AI Assistant (ZoRo)** — Conversational AI powered by Groq (`llama-3.3-70b-versatile`) via secure Vercel Serverless Functions. Answers questions about projects, skills, education, and experience.
- 📌 **Project-Specific AI Context** — Click **✦ Ask AI** on any project card for a focused AI conversation about that project's architecture and tech stack.
- 📊 **Live Coding Stats** — Real-time GitHub & LeetCode stats fetched via API.
- 🎨 **Cyber-Minimalist Dark Theme** — Neon green + electric indigo palette, glassmorphism, and smooth Framer Motion animations.
- 📱 **Fully Responsive** — Optimized mobile experience including keyboard-aware AI chat panel.
- 📬 **Contact Form** — Functional email delivery via Web3Forms.
